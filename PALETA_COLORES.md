# Paleta de colores

Paleta visual utilizada en ByteCon UMG 2026, extraída de `styles.css`.

| Nombre | Valor | Uso principal |
| --- | --- | --- |
| Papel oscuro | `#071C33` | Fondo principal y texto sobre acentos claros. |
| Azul noche | `#06172C` | Fondos de la sección de anuncio y eventos anteriores. |
| Azul profundo | `#0A213A` | Fondos de secciones oscuras como ponentes y entradas. |
| Azul medio | `#1D5E96` | Tarjetas y acentos secundarios. |
| Azul tarjeta | `#103756` | Fondo de la tarjeta de entradas. |
| Cian claro | `#EAFBFF` | Texto principal y superficies claras. |
| Cian eléctrico | `#52E3F2` | Color de acento, botones, destacados y bordes. |
| Violeta | `#8B63FF` | Acentos, tarjetas y sección de experiencia. |
| Blanco | `#FFFFFF` | Fondo del enlace de accesibilidad al recibir foco. |

## Variaciones translúcidas

| Valor | Uso principal |
| --- | --- |
| `rgba(82, 227, 242, 0.18)` | Número decorativo de la portada. |
| `rgba(82, 227, 242, 0.25)` | Líneas y bordes sutiles. |
| `rgba(82, 227, 242, 0.35)` | Órbitas decorativas. |
| `rgba(82, 227, 242, 0.6)` | Borde de las tarjetas de eventos. |
| `rgba(7, 28, 51, 0.45)` | Superposición sobre la imagen de experiencia. |
| `rgba(7, 28, 51, 0.74 - 0.92)` | Superposiciones oscuras sobre imágenes. |
| `rgba(255, 255, 255, 0.08)` | Fondo sutil de los retratos de ponentes. |
